# Ashrith B A — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract this ZIP.
2. Open the `ashrith-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Deploy on Vercel
1. Create a GitHub repository (for example, `ashrith-portfolio`).
2. Upload the contents of this folder to the repository root.
3. In Vercel, choose **Add New → Project**, import the GitHub repository.
4. Keep Framework Preset as **Other**. No build command is needed; output directory can be `.`.
5. Deploy.

## Personalisation before publishing
- Confirm the internship dates and descriptions.
- Add your preferred public email address and phone number if you want them displayed.
- Add direct GitHub repository links for individual projects if available.
- Add a current resume PDF in `assets/` and link it from the hero if desired.
- Check that all listed skills are current and that you can discuss them in an interview.

## Files
- `index.html` — page content
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation and reveal animations
- `assets/ashrith-profile.jpg` — supplied professional portrait


## Profile positioning
This version presents Ashrith as a general technology/software development candidate. AI/ML is included as one area of interest, not the sole specialization. Review all experience dates, project descriptions and skill levels before publishing.
